# WhatsBackup

[English](README.md) · [简体中文](README.zh-CN.md) · [Português](README.pt-BR.md) · [Español](README.es.md) · [العربية](README.ar.md) · [Bahasa Indonesia](README.id.md) · [हिन्दी](README.hi.md) · [Français](README.fr.md) · [Türkçe](README.tr.md)

Application de bureau pour Windows et Mac qui sauvegarde les discussions WhatsApp et les transfère entre iPhone et Android.

## Téléchargement

| Système | Installateur |
| --- | --- |
| Windows 10 (1809) ou version ultérieure, 64 bits | [Dernière version](https://github.com/yuflux1/WhatsBackup/releases/latest) |
| Mac avec puce Apple | [Dernière version](https://github.com/yuflux1/WhatsBackup/releases/latest) |

Sur la page de publication, téléchargez le fichier dont le nom contient `windows-x64` ou `macos-arm64`.

Sous Windows, lancez le programme d’installation. Pour connecter un iPhone, laissez la prise en charge des appareils Apple cochée et acceptez la demande d’administrateur. Sous Android, activez le débogage USB et acceptez cet ordinateur sur le téléphone.

Sous Mac, ouvrez l’image disque et faites glisser l’application dans Applications. Ce paquet est prévu pour les puces Apple.

Après l’installation, l’application s’appelle YiTrans Desktop.

## Essai

Vous pouvez essayer l’application après l’installation. Pour transférer la sauvegarde complète, achetez un code de licence sur Telegram.

L’essai de chaque sauvegarde contient un ensemble fixe d’au plus 20 messages texte. Un nouvel essai envoie les mêmes messages. Les pièces jointes et l’historique des appels sont transférés avec la licence complète. La sauvegarde d’origine reste sur l’ordinateur. Sauvegardez le téléphone de destination avant d’y écrire.

## Acheter un code de licence

Achetez le code de licence sur Telegram. Après l’achat, il est lié à un seul ordinateur :

[https://t.me/+13323554870](https://t.me/+13323554870)

Les noms en gras sont les libellés de l’interface en anglais.

1. Dans l’application, cliquez sur **Activate full transfer**.
2. Copiez le **Computer code**.
3. Ouvrez le Telegram ci-dessus, envoyez le code de l’ordinateur et achetez un code de licence.
4. Collez le code complet dans **License code**. Le code commence par `YT1.`.
5. Cliquez sur **Activate full transfer**.
6. Convertissez à nouveau la sauvegarde d’origine, puis lancez le transfert complet.
