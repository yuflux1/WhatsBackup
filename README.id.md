# WhatsBackup

[English](README.md) · [简体中文](README.zh-CN.md) · [Português](README.pt-BR.md) · [Español](README.es.md) · [العربية](README.ar.md) · [Bahasa Indonesia](README.id.md) · [हिन्दी](README.hi.md) · [Français](README.fr.md) · [Türkçe](README.tr.md)

Aplikasi desktop untuk Windows dan Mac yang mencadangkan chat WhatsApp dan memindahkannya antara iPhone dan Android.

## Unduh

| Sistem | Pemasang |
| --- | --- |
| Windows 10 (1809) atau yang lebih baru, 64-bit | [Rilis terbaru](https://github.com/yuflux1/WhatsBackup/releases/latest) |
| Mac dengan chip Apple | [Rilis terbaru](https://github.com/yuflux1/WhatsBackup/releases/latest) |

Di halaman rilis, unduh berkas yang namanya berisi `windows-x64` atau `macos-arm64`.

Di Windows, jalankan pemasang. Saat menghubungkan iPhone, biarkan dukungan perangkat Apple tetap dipilih dan setujui permintaan administrator. Di Android, aktifkan debugging USB dan izinkan komputer ini di ponsel.

Di Mac, buka disk image dan seret aplikasi ke Applications. Paket ini untuk chip Apple.

Setelah dipasang, nama aplikasinya adalah YiTrans Desktop.

## Uji coba

Anda dapat mencoba setelah memasang aplikasi. Untuk mentransfer cadangan secara lengkap, beli kode lisensi melalui Telegram.

Uji coba setiap cadangan berisi satu set tetap paling banyak 20 pesan teks. Mengulang uji coba mengirim pesan yang sama. Lampiran dan riwayat panggilan ditransfer setelah lisensi penuh. Cadangan asli tetap ada di komputer. Cadangkan ponsel tujuan sebelum menulis data ke ponsel itu.

## Beli kode lisensi

Beli kode lisensi melalui Telegram. Setelah dibeli, kode ini terikat pada satu komputer:

[https://t.me/+13323554870](https://t.me/+13323554870)

Nama yang ditebalkan adalah label pada antarmuka bahasa Inggris.

1. Di aplikasi, klik **Activate full transfer**.
2. Salin **Computer code**.
3. Buka Telegram di atas, kirim kode komputer, dan beli kode lisensi.
4. Tempel kode lisensi lengkap ke **License code**. Kode dimulai dengan `YT1.`.
5. Klik **Activate full transfer**.
6. Konversi lagi cadangan asli, lalu jalankan transfer lengkap.
