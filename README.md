# WhatsBackup

[English](README.md) · [简体中文](README.zh-CN.md) · [Português](README.pt-BR.md) · [Español](README.es.md) · [العربية](README.ar.md) · [Bahasa Indonesia](README.id.md) · [हिन्दी](README.hi.md) · [Français](README.fr.md) · [Türkçe](README.tr.md)

A desktop app for Windows and Mac that backs up WhatsApp chats and moves them between iPhone and Android.

## Download

| System | Installer |
| --- | --- |
| Windows 10 (1809) or later, 64-bit | [Latest release](https://github.com/yuflux1/WhatsBackup/releases/latest) |
| Mac with Apple silicon | [Latest release](https://github.com/yuflux1/WhatsBackup/releases/latest) |

On the release page, download the file whose name contains `windows-x64` or `macos-arm64`.

On Windows, run the setup program. When connecting an iPhone, leave Apple device support selected and approve the administrator prompt. On Android, turn on USB debugging and accept this computer on the phone.

On Mac, open the disk image and drag the app into Applications. This package runs on Apple silicon.

After installation, the app is named YiTrans Desktop.

## Trial

You can try the app after installing it. To transfer the full backup, buy a license code on Telegram.

Each backup trial contains one fixed set of up to 20 text messages. Running the trial again sends the same messages. Attachments and call history are transferred after you have a full license. The original backup stays on the computer. Back up the target phone before writing to it.
