# WhatsBackup

[English](README.md) · [简体中文](README.zh-CN.md) · [Português](README.pt-BR.md) · [Español](README.es.md) · [العربية](README.ar.md) · [Bahasa Indonesia](README.id.md) · [हिन्दी](README.hi.md) · [Français](README.fr.md) · [Türkçe](README.tr.md)

Windows 和 Mac 上的桌面软件，用于备份 WhatsApp 聊天记录，并在 iPhone 与 Android 之间迁移。

## 下载

| 系统 | 安装包 |
| --- | --- |
| Windows 10（1809）或更高版本，64 位 | [最新版本](https://github.com/yuflux1/WhatsBackup/releases/latest) |
| Mac（Apple 芯片） | [最新版本](https://github.com/yuflux1/WhatsBackup/releases/latest) |

在发布页面下载文件名中带 `windows-x64` 或 `macos-arm64` 的安装包。

Windows 上直接运行安装程序。连接 iPhone 时，请保留 Apple 设备支持组件，并允许管理员权限请求。连接 Android 时，打开 USB 调试，并在手机上同意这台电脑的授权。

Mac 上打开磁盘映像，把应用拖进“应用程序”。此安装包适用于 Apple 芯片。

安装后的软件名称是 YiTrans Desktop。

## 试用

安装后可以先试用。需要完整传输时，通过 Telegram 购买授权码。

每份备份的试用内容是固定的最多 20 条文字消息。再次试传仍是这同一批消息。附件和通话记录在完整授权后传输。原始备份会保留在电脑上。写入目标手机前，请先备份那部手机。

## 购买授权码

授权码通过 Telegram 购买，购买后绑定一台电脑：

[https://t.me/+13323554870](https://t.me/+13323554870)

1. 在软件中点击 **激活完整传输**。
2. 复制 **本机机器码**。
3. 打开上面的 Telegram，发送机器码并购买授权码。
4. 把收到的完整授权码粘贴到 **授权码**。授权码以 `YT1.` 开头。
5. 点击 **激活完整传输**。
6. 从原始备份重新转换，再进行完整传输。
