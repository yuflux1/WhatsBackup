# WhatsBackup

[English](README.md) · [简体中文](README.zh-CN.md) · [Português](README.pt-BR.md) · [Español](README.es.md) · [العربية](README.ar.md) · [Bahasa Indonesia](README.id.md) · [हिन्दी](README.hi.md) · [Français](README.fr.md) · [Türkçe](README.tr.md)

Aplicativo de desktop para Windows e Mac que faz backup das conversas do WhatsApp e as transfere entre iPhone e Android.

## Download

| Sistema | Instalador |
| --- | --- |
| Windows 10 (1809) ou posterior, 64 bits | [Versão mais recente](https://github.com/yuflux1/WhatsBackup/releases/latest) |
| Mac com chip da Apple | [Versão mais recente](https://github.com/yuflux1/WhatsBackup/releases/latest) |

Na página da versão, baixe o arquivo cujo nome contém `windows-x64` ou `macos-arm64`.

No Windows, execute o instalador. Ao conectar um iPhone, mantenha o suporte a dispositivos Apple selecionado e aceite o pedido de permissão de administrador. No Android, ative a depuração USB e aceite este computador no telefone.

No Mac, abra a imagem de disco e arraste o aplicativo para Aplicativos. Este pacote funciona em chips da Apple.

Depois da instalação, o aplicativo se chama YiTrans Desktop.

## Teste

Você pode testar depois de instalar. Para transferir o backup completo, compre um código de licença pelo Telegram.

O teste de cada backup contém um conjunto fixo de até 20 mensagens de texto. Repetir o teste envia as mesmas mensagens. Anexos e histórico de chamadas são transferidos com a licença completa. O backup original permanece no computador. Faça backup do telefone de destino antes de gravar nele.

## Comprar o código de licença

Compre o código de licença pelo Telegram. Depois da compra, ele fica vinculado a um computador:

[https://t.me/+13323554870](https://t.me/+13323554870)

Os nomes em negrito abaixo são os rótulos da interface em inglês.

1. No aplicativo, clique em **Activate full transfer**.
2. Copie o **Computer code**.
3. Abra o Telegram acima, envie o código do computador e compre o código de licença.
4. Cole o código completo em **License code**. O código começa com `YT1.`.
5. Clique em **Activate full transfer**.
6. Converta novamente o backup original e faça a transferência completa.
